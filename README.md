# The OWL AdBlocker

The OWL AdBlocker is a lightweight, full-fledged adblocker extension designed specifically for Firefox. Built entirely on the modern Manifest V3 `declarativeNetRequest` API, it operates silently in the background with zero UI bloat to provide lightning-fast, native adblocking.

## Features

- **Comprehensive Blocking:** Powered by Peter Lowe's Ad and tracking server list, featuring over 3,500 highly-efficient blocking rules.
- **Zero UI Bloat:** No popups, no options pages, and no background scripts consuming memory. Just pure, native filtering.
- **Manifest V3:** Utilizes the latest WebExtensions APIs for maximum performance and security.
- **Firefox Native:** Specifically configured and optimized for Mozilla Firefox.

## Installation

You can load the extension temporarily in Firefox for testing or install it via the provided zip file.

1. Open Firefox and navigate to `about:debugging`.
2. Click on **This Firefox** in the sidebar.
3. Click the **Load Temporary Add-on...** button.
4. Select the `the_Owl_extension.zip` file (or the `manifest.json` file inside the unzipped folder).

*The extension will start blocking ads and trackers immediately.*

## Development

The extension rules are generated by fetching and converting [Peter Lowe's list](https://pgl.yoyo.org/adservers/) into a compatible `declarativeNetRequest` format (`rules.json`).
